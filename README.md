# 雙人全方位價值觀測驗

一份可以讓兩個人分別填寫、再比較價值觀相似程度的互動式網頁測驗。純前端、不需安裝，所有資料只存在填寫者的瀏覽器與下載的檔案中。

## 內容

- **15 大面向 × 5 題 = 75 題**：人生觀、金錢觀、道德與是非觀、社會與公平觀、家庭觀、友情與人際觀、工作與事業觀、生活方式與享樂觀、自由與個人界線、情緒與衝突處理、學習與成長觀、科技與環境觀、風險與安全觀、愛情與親密關係觀、生命與幸福觀
- **1～5 分量表**：1＝非常不同意，5＝非常同意，全部必填
- 顯示填寫進度、可輸入名稱、自動暫存作答
- 完成後下載包含所有題目與答案的 JSON 檔

## 使用方式

1. 兩個人各自打開 `quiz.html` 填寫，完成後各自下載 JSON 答案檔。
2. 打開 `analysis.html`，上傳兩份 JSON 檔，按「開始分析」。
3. **無法下載檔案時**（常見於 LINE、Instagram、Facebook 等 App 的內建瀏覽器）：
   - 頁面頂端會提示改用系統瀏覽器開啟；LINE 可直接點「用系統瀏覽器開啟」。
   - 或在完成後按「複製答案」，取得一段簡短的答案代碼（`VQ1-` 加 75 個數字），傳給對方或貼到分析頁的「貼上答案文字」。
4. 想先看報告長什麼樣子，可以按「載入範例資料試看」，或直接開啟 `analysis.html#demo`。

## 分析內容

1. 整體價值觀相似度（百分比）
2. 15 大面向各自的相似度（長條圖＋傾向位置圖＋明細表）
3. 雙方最相似的 5 個價值觀
4. 雙方差異最大的 5 個價值觀
5. 所有回答差距達 2 分以上的題目
6. 雙方各自的價值觀與人格傾向
7. 對人生、金錢、道德、工作及生活的核心追求
8. 可能產生衝突的價值觀
9. 哪些差異可能互補、哪些需要溝通
10. 值得雙方深入討論的問題

## 計算方式

- 每題相似度＝100%－（雙方答案差距 × 25%）
- 各面向相似度＝該面向 5 題的平均；整體相似度＝75 題的平均
- 個人傾向分數：各面向 5 題的平均（反向題以 6－分數計算），用來描述偏向該面向的哪一端

分析報告由網頁依固定規則產生。若想要更深入的文字解讀，也可以把兩份 JSON 檔交給 AI 助理分析。

> 百分比只代表這份自訂測驗的回答接近程度，不代表科學驗證的感情契合度，也不能用來預測關係成敗。問卷結果不是心理診斷，也不能用來推斷一個人的真實行為。

## 檔案結構

```
index.html      首頁
quiz.html       填寫頁
analysis.html   雙人分析頁
css/style.css   樣式（支援深色模式、手機版）
js/questions.js 題庫與面向設定
js/quiz.js      填寫邏輯與 JSON 匯出
js/analysis.js  比較分析與報告產生
js/inapp.js     偵測 App 內建瀏覽器並顯示提示
```
